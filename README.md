# Desktop-Inspired Developer Portfolio 🖥️✨

A high-performance, desktop-styled personal portfolio featuring a dark glassmorphism UI, fluid tabbed navigation, and an immersive user experience. Designed to showcase projects, technical background, and professional experience with a unique aesthetic twist.

## 🚀 Live Demo
Check out the live site here: [https://jordaineforde.github.io/Portfolio-2/](https://jordaineforde.github.io/Portfolio-2/)

## 💻 Tech Stack
* **HTML5:** Semantic, accessible markup structure.
* **CSS3:** Custom styling featuring dark glassmorphism effects, responsive layouts, and modern design principles.
* **JavaScript:** Dynamic component rendering, interactive tab management, and smooth navigation handlers.

## 📂 Project Structure & Features
* **Home:** Introduction and quick-access dashboard.
* **About:** Background overview detailing my journey as an undergraduate student pursuing Computing with a specialisation in Artificial Intelligence at the University of Greenwich, alongside my interests in software engineering, data analytics, and tech policy.
* **Projects:** Interactive showcase of technical work, academic coursework, and applications.
* **CV:** Embedded professional resume view and download options.
* **Contact:** Fully updated communication channels including email, GitHub, and LinkedIn integration.
